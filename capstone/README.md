# Capstone Project

> Status: ⬜ **Planned**

The final project will combine the skills developed throughout this repository into one documented cloud infrastructure project.

The target direction is an **automated Azure network/infrastructure environment** combining:

- Azure networking
- Linux
- Security controls
- Terraform
- Ansible
- Python automation
- CI/CD
- Monitoring
- Troubleshooting scenarios

The exact architecture will be defined after the foundational labs are complete.
