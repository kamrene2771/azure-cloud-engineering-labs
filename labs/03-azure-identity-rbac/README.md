# Lab 03 — Azure Identity & RBAC: Least Privilege Access

> Status: 🔄 **In progress**  
> Region: **Belgium Central**

This lab demonstrates Azure identity and authorization using user-assigned managed identities, Azure RBAC, least-privilege access, and the distinction between control-plane and data-plane permissions.

## Lab goals

- Compare `Storage Blob Data Reader` and `Storage Blob Data Contributor`
- Prove successful read access and denied write access
- Prove successful operator write access
- Compare the built-in `Reader` role with Blob data roles
- Demonstrate control-plane vs data-plane authorization
- Use Private Endpoint and Private DNS for private storage access
- Capture meaningful troubleshooting evidence
